# 大锤角色 Mod

基于 RitsuLib `0.5.12` 的《杀戮尖塔 2》角色 Mod。当前已完成首版 52 张普通职业牌、1 张先古牌、1 张生成状态牌、8 件职业遗物、4 瓶职业药水及其核心规则实现，用于游戏内机制验收与平衡测试；卡牌、遗物与药水暂用与设计顺序对应的独立编号图，角色美术仍为占位资源。

## 当前可玩内容

- 可选角色：`大锤猎人`，暂用项目内绘制的全身 SVG 大锤猎人、铁甲战士的缺省音效与模板占位场景。
- 初始卡组：4 张`纵挥`、4 张`翻滚`、1 张`蓄力`、1 张`大地一击`。
- 完整首版牌池：53 种可收集牌，包括 4 种初始牌、16 张白卡、22 张蓝卡、10 张金卡和 1 张先古牌；另有生成状态牌`重新起身`，数值见 [hammer_card_design.md](./hammer_card_design.md)。
- 官方卡对照与本轮调整依据见 [card_balance_review.md](./card_balance_review.md)。
- 联机限定牌：`捞飞队友`、`鬼人粉尘`和`硬化粉尘`只在联机奖励中出现；`重整架势`也可在单人模式获得。
- 先古牌：古旧之牙会将`大地一击`超越为`天地大冲撞`并保留升级与附魔；尘封魔典也会优先将其作为大锤猎人候选。
- 初始遗物：`锤术护石`，你的回合开始时若没有蓄力，获得 1 级蓄力。
- 完整首版遗物池：8 件遗物，覆盖蓄力、防御、晕眩和相杀联动，包括商店遗物`回避衣装`和`不动衣装`。
- 完整首版药水池：4 瓶职业药水，包括`强走药G`、`闪光弹`、`忍耐种子`和`怪力种子`。
- 蓄力：0 至 3 级，跨回合保留；敌人攻击造成未格挡伤害时清空；释放牌结算后释放全部蓄力。
- 晕眩：所有敌人的初始阈值均为 10。达到阈值后调用游戏原生击晕，清空当前晕眩值；同一敌人每次被击晕后，下次阈值翻倍为 20、40、80……
- 已实现蓄力、晕眩、相杀以及阻挡联动牌，并复用原生阻挡、虚弱、易伤、能量和延迟抽牌规则。

`大地一击`使用冻结设计稿中的数值：

| 蓄力 | 0 | 1 | 2 | 3 |
|---|---:|---:|---:|---:|
| 伤害 | 11 | 16 | 22 | 30 |
| 晕眩值 | 0 | 2 | 4 | 5 |
| 升级伤害 | 15 | 20 | 27 | 36 |
| 升级晕眩值 | 1 | 3 | 5 | 6 |

## 工程结构

```text
HammerModCode/
  Cards/        54 个卡牌模型及共享结算基类
  Characters/   角色及卡牌、遗物、药水池
  Gameplay/     蓄力、受击清空和晕眩结算
  Powers/       晕眩、蓄力和职业能力的持续状态
  Relics/       8 件职业遗物
  Potions/      4 瓶职业药水
HammerMod/      Godot 场景、占位图片和中英文本地化
```

关键实现遵循 RitsuLib 文档的职责划分：

- `ModTypeDiscoveryHub.RegisterModAssembly` 发现带注册注解的内容。
- `ModCharacterTemplate` 和 additive starter attributes 组装角色及初始内容。
- `SecondaryResourceDefinition`、`SecondaryResourceCmd` 和自定义的辉星式单数字计数器管理蓄力。
- `HookedSingletonModel` 监听受伤结果，不需要自有 Harmony 补丁。
- `CreatureCmd.Stun` 复用游戏原生击晕。

## 本机配置

`local.props` 已按当前 Mac 环境配置并被 Git 忽略。迁移电脑时，复制 `local.props.template` 为 `local.props`，修改游戏目录、`sts2.dll` 目录和 MegaDot 可执行文件路径。

项目固定引用：

- STS2 API：`0.107.1`（与当前本机游戏版本一致）
- RitsuLib：`STS2.RitsuLib.Compat.0.107.1` `0.5.12`
- .NET：`net9.0`
- Godot/MegaDot：`4.5.1`

## 构建

只验证 C#：

```bash
/usr/local/share/dotnet/dotnet build HammerMod.csproj \
  /p:CopyModOnBuild=false \
  /p:RunPckExport=false
```

生成可部署的 DLL、manifest、PCK 和 RitsuLib 到 `.deploy/`：

```bash
/usr/local/share/dotnet/dotnet build HammerMod.csproj -c Release \
  /p:CopyModOnBuild=true \
  /p:RunPckExport=true
```

macOS 上，游戏从**可执行文件旁边**读取本地 Mod，因此不是 Steam 游戏根目录，而是：

```text
SlayTheSpire2.app/Contents/MacOS/mods/
├── STS2-RitsuLib/
└── HammerMod/
```

将 `.deploy/STS2-RitsuLib` 和 `.deploy/HammerMod` 分别复制到上述同名目录。首次发现 Mod 时，游戏会要求确认启用 Mod；确认后需要重启一次。Windows 的可执行文件就在游戏根目录，因此其默认位置仍是 `Slay the Spire 2/mods/`。

## 打包给测试者

执行下面的脚本会重新构建 Release 版，并在 `dist/` 生成带时间戳的 ZIP 和对应的 SHA-256 文件：

```bash
./tools/package_test_build.sh
```

测试包包含两个并列的运行时 Mod 目录：`HammerMod` 以及当前工程固定依赖的 `STS2-RitsuLib 0.5.12`。同时附带安装说明、`build-info.json` 和 RitsuLib 的 MIT 许可文本；测试者只需把压缩包中的 `mods/` 放到游戏可执行文件所在目录。每次发包前先提高 `HammerMod.json` 的 `version`，以免不同测试版本都显示为同一个版本号。

## 本轮验收

1. 角色选择中能看到并选择`大锤猎人`。
2. 进入战斗后，能量球右侧的蓄力 UI 显示 1；蓄力变化时数字在 0 至 3 之间同步刷新。
3. `蓄力`使数值最多增加到 3，且升级后费用为 0。
4. `大地一击`随蓄力实时改变显示与伤害，结算后蓄力归零。
5. 敌人攻击穿透格挡后蓄力归零，完全格挡时保留。
6. 对普通敌人累计 10 点晕眩值后，敌人被原生击晕；下一次阈值为 20。
7. 单人卡牌奖励中有 45 张普通候选牌；联机时增加 3 张联机限定牌，中英文名称与数值正常。
8. 按设计稿末尾的“优先测试组合”验证超蓄力、KO术、打桩高手和迎面相杀的组合结算。
9. 获得古旧之牙时，`大地一击`转化为`天地大冲撞`并保留升级；尘封魔典能为大锤猎人提供该牌。
10. 初始遗物为`锤术护石`；其余 7 件遗物能在对应稀有度池中出现，并按描述触发。
11. 4 瓶职业药水能在药水奖励中出现；`怪力种子`的力量仅持续本回合，`忍耐种子`的蓄力保护持续至下回合开始。
12. 遗物和药水分别显示 01-08、01-04 的独立编号占位图。
13. `重整架势`能从弃牌堆选牌置顶；联机限定牌不会出现在单人奖励中。
14. `捞飞队友`只能选择队友，正确给予延迟能量并把归属于目标的`重新起身`加入其手牌。
