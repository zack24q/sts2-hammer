# 大锤角色 Mod

基于 RitsuLib `0.5.13` 的《杀戮尖塔 2》角色 Mod。当前已完成 86 张普通职业牌、1 张先古牌、1 张生成状态牌、8 件职业遗物、5 瓶职业药水及其核心规则实现，用于游戏内机制验收与平衡测试；卡牌仍暂用占位资源，角色、状态、遗物与药水已接入本地测试美术，其中用户提供素材的再分发权仍待确认。

## 当前可玩内容

- 可选角色：`大锤猎人`，使用粉色兽骨甲猎人的选人、战斗待机与倒地立绘，暂用铁甲战士的缺省音效与模板场景。
- 初始卡组：4 张`纵挥`、4 张`翻滚`、1 张`蓄力`、1 张`大地一击`。
- 当前牌池：87种可收集牌，包括4种初始牌、20张白卡、36张蓝卡、26张金卡和1张先古牌；另有生成状态牌`倒地起身`，数值见[hammer_card_design.md](./hammer_card_design.md)。
- 官方卡对照与本轮调整依据见 [card_balance_review.md](./card_balance_review.md)。
- 联机限定牌：`捞飞队友`、`鬼人粉尘`和`硬化粉尘`只在联机奖励中出现；`重整架势`也可在单人模式获得。
- 先古牌：古旧之牙会将`大地一击`超越为`天地大冲撞`并保留升级与附魔；尘封魔典也会优先将其作为大锤猎人候选。
- 初始遗物：`锤术护石`，你的回合开始时获得 1 级蓄力；精炼后每回合将蓄力提升至满级。
- 完整首版遗物池：8 件遗物，覆盖蓄力、防御、晕眩和相杀联动，包括商店遗物`回避衣装`和`不动衣装`。
- 完整首版药水池：5 瓶职业药水，包括`强走药`、`闪光弹`、`忍耐药丸`、`怪力药丸`和稀有药水`落穴`。
- 蓄力：0 至 3 级，跨回合保留；敌人攻击的未格挡伤害达到5/10/15点时分别失去1/2/3级；释放牌结算后释放全部蓄力。
- 晕眩：所有敌人的初始阈值均为 10。达到阈值后调用游戏原生击晕，清空当前晕眩值；同一敌人每次被击晕后，下次阈值翻倍为 20、40、80……敌人的晕眩状态说明会实时显示“当前晕眩值/本次阈值”。
- 已实现蓄力、晕眩、相杀以及阻挡联动牌，并复用原生阻挡、虚弱、易伤、能量和延迟抽牌规则。

`大地一击`使用冻结设计稿中的数值：

| 蓄力 | 0 | 1 | 2 | 3 |
|---|---:|---:|---:|---:|
| 伤害 | 12 | 16 | 22 | 30 |
| 晕眩值 | 1 | 2 | 4 | 6 |
| 升级伤害 | 15 | 20 | 27 | 36 |
| 升级晕眩值 | 2 | 3 | 6 | 8 |

## 工程结构

```text
HammerModCode/
  Cards/        88 个卡牌模型及共享结算基类
  Characters/   角色及卡牌、遗物、药水池
  Gameplay/     蓄力、受击降级和晕眩结算
  Powers/       晕眩、蓄力和职业能力的持续状态
  Relics/       8 件职业遗物
  Potions/      5 瓶职业药水
HammerMod/      Godot 场景、运行时图片和中英文本地化
```

关键实现遵循 RitsuLib 文档的职责划分：

- `ModTypeDiscoveryHub.RegisterModAssembly` 发现带注册注解的内容。
- `ModCharacterTemplate` 和 additive starter attributes 组装角色及初始内容。
- `SecondaryResourceDefinition`、`SecondaryResourceCmd` 和自定义的大锤计数器管理蓄力；数字位于图标下方，1/2/3级分别显示逐级扩大的红、橙、白色边缘光。
- `HookedSingletonModel` 监听受伤与战后奖励结果；`满足感`仅在官方药水移除入口使用一个前置 Harmony 补丁保留下一瓶药水，其余药水流程保持原样。
- `CreatureCmd.Stun` 复用游戏原生击晕；相关卡牌悬停说明统一使用 `StaticHoverTip.Stun` 及其原生图标，不再注册独立的 `STUN` 关键字。

## 本机配置

`local.props` 已按当前 Mac 环境配置并被 Git 忽略。迁移电脑时，复制 `local.props.template` 为 `local.props`，修改游戏目录、`sts2.dll` 目录和 MegaDot 可执行文件路径。

项目固定引用：

- STS2 API：`0.107.1`（与当前本机游戏版本一致）
- RitsuLib：`STS2.RitsuLib.Compat.0.107.1` `0.5.13`
- .NET：`net9.0`
- Godot/MegaDot：`4.5.1`

## 构建

只验证 C#：

```bash
/usr/local/share/dotnet/dotnet build HammerMod.csproj \
  /p:CopyModOnBuild=false \
  /p:RunPckExport=false
```

生成可部署的 DLL、manifest、PCK 和 RitsuLib 到 `.deploy/`：

```bash
/usr/local/share/dotnet/dotnet build HammerMod.csproj -c Release \
  /p:CopyModOnBuild=true \
  /p:RunPckExport=true
```

macOS 上，游戏从**可执行文件旁边**读取本地 Mod，因此不是 Steam 游戏根目录，而是：

```text
SlayTheSpire2.app/Contents/MacOS/mods/
├── STS2-RitsuLib/
└── HammerMod/
```

将 `.deploy/STS2-RitsuLib` 和 `.deploy/HammerMod` 分别复制到上述同名目录。首次发现 Mod 时，游戏会要求确认启用 Mod；确认后需要重启一次。Windows 的可执行文件就在游戏根目录，因此其默认位置仍是 `Slay the Spire 2/mods/`。

## 打包给测试者

执行下面的脚本会重新构建 Release 版，并在 `dist/` 生成带时间戳的 ZIP 和对应的 SHA-256 文件：

```bash
./tools/package_test_build.sh
```

测试包包含两个并列的运行时 Mod 目录：`HammerMod` 以及当前工程固定依赖的 `STS2-RitsuLib 0.5.13`。同时附带安装说明、`build-info.json` 和 RitsuLib 的 MIT 许可文本；测试者只需把压缩包中的 `mods/` 放到游戏可执行文件所在目录。每次发包前先提高 `HammerMod.json` 的 `version`，以免不同测试版本都显示为同一个版本号。

## 本轮验收

1. 角色选择中能看到并选择`大锤猎人`。
2. 进入战斗后，心形宝石能量图标左下方的蓄力 UI 显示 1；数字位于大锤下方，0级无光，1/2/3级分别显示逐级扩大的红、橙、白色边缘光。
3. `蓄力`使数值最多增加到 3，且升级后费用为 0。
4. `大地一击`随蓄力实时改变显示与伤害，结算后蓄力归零。
5. 敌人攻击造成的未格挡伤害达到5/10/15点时，分别失去1/2/3级蓄力；低于5点时保留蓄力。
6. 对普通敌人累计 10 点晕眩值后，敌人被原生击晕；下一次阈值为 20。敌人状态说明分别显示`当前值/10`和`当前值/20`。
7. 单人卡牌奖励中有 79 张普通候选牌；联机时增加 3 张联机限定牌，共 82 张普通候选牌，中英文名称与数值正常。
8. 按设计稿末尾的“优先测试组合”验证超蓄力、KO术、打桩高手和迎面相杀的组合结算。
9. 获得古旧之牙时，`大地一击`转化为`天地大冲撞`并保留升级；尘封魔典能为大锤猎人提供该牌。
10. 初始遗物`锤术护石`每回合开始获得1级蓄力，精炼后每回合将蓄力提升至满级；其余 7 件遗物能在对应稀有度池中出现，并按描述触发。
11. 5 瓶职业药水能在药水奖励中出现；`怪力药丸`本回合给予10点力量，`忍耐药丸`给予24点格挡，`落穴`选择一个敌人，直到敌方回合结束只令该目标对自己的伤害变为0并给予3层易伤。
12. 遗物和药水均使用与模型类名对应的独立 256x256 PNG，战斗状态使用对应的专用图标。
13. `重整架势`能从弃牌堆选牌置顶；联机限定牌不会出现在单人奖励中。
14. `捞飞队友`只能选择队友，正确给予8/10点格挡、2点力量和延迟能量，并把归属于目标的`倒地起身`加入其手牌。
15. `借力挥击`只在目标打出前具有攻击意图时返还1点能量；`收锤居合`至少拥有1级蓄力即可打出，并把失去的每级蓄力转化为2点能量；`乘胜追击`在条件满足时获得2点能量并抽2张牌。
16. `锤柄打击`造成9点伤害并抽1/2张牌；`快捷调合`抽牌后强制选择1张当前手牌置于抽牌堆顶部。
17. `扫腿重锤`升级后对攻击意图敌人给予2层虚弱；`山崩地裂`造成24/32点伤害并分别增加10/13点晕眩值。
18. `连续横挥`按3×2/3×3结算；`再来一锤`只为原本至少2段的攻击增加3/5段，单段`横扫开路`不受影响。
19. `横扫开路`以1费对所有敌人造成6/9点伤害并抽1张牌；`龙卷风摧毁停车场`基础攻击X次、升级攻击X+1次，二者均在全部群体伤害后增加2X点晕眩。
20. `破坏王`在整张攻击牌结算后逐个检查敌人，每张牌对每个受到未格挡攻击伤害且仍存活的敌人只施加一次易伤。
21. `挑战者`仅在回合开始时存在攻击意图敌人才给予本回合力量；`翔虫续力`响应任意实际消耗至少2点能量的牌，首次打出自身不触发；`越砸越疼`每次以3级以上蓄力打出释放牌都获得3点力量。
22. 多段攻击在战斗手牌中显示当前最终段数；`浑身蓄力回旋`随蓄力、`捣年糕`随目标击晕状态、`龙卷风摧毁停车场`随当前X值实时刷新，并计入`再来一锤`。牌库、奖励和升级预览显示原始段数。
23. `客制吸血`为2/1费能力；在整张攻击结算后，按每个敌人在该次攻击中实际失去的总生命值分别计算，每满10点回复1点生命；多段伤害先汇总再计算，格挡与击杀后的过量伤害不计入。
24. `手摇拖拉机`为2费技能，使抽牌堆中一张随机释放蓄力牌获得1层原生重放；基础版消耗，升级后去掉消耗。鼠标提示使用本体静态`重放`说明，释放牌在整组重放末次结束后才清空蓄力。
25. `震荡护身`为0费，按打出时所有存活敌人的当前晕眩值求和并获得等量格挡；基础版消耗，升级后去掉消耗。
26. `KO术`在整张攻击牌结算后按实际支付能量额外施加晕眩，基础版等于实际耗能，升级后为实际耗能+1；多段攻击每张牌只触发一次。
27. `倒地起身`花费1点能量、抽1张牌并消耗；`滑走强化`为0费技能，按是否至少拥有2级蓄力，本回合获得2/4点力量，升级后为4/6点。
28. `蓄力变化·武`为1费，按当前蓄力等级提供等量力量；获得、失去或释放蓄力后实时调整，多张能力按张数叠加，升级后添加固有。
29. `回复药`是1费蓝卡技能；仅当所有敌人都不是攻击意图或攻击总伤害为0时可打出，获得5点再生并消耗，升级后添加保留。
30. `超蓄力`使本回合释放蓄力牌免费且不清空蓄力；基础版消耗，升级后移除消耗。
31. `余势不绝`每回合第一次以3级以上蓄力打出释放牌时获得1点能量并抽2张牌，升级后费用降为0；多张叠加共享触发次数并按层数结算。
32. `转祸为福`在虚弱、易伤、脆弱之间合计至多移除5层，并按实际移除层数获得1/2倍力量；`满足感`只保留下一瓶实际使用的药水；`激运票`在本场战斗的卡牌奖励上提供一次与`浮木`相同的重掷。
33. `蓄力变化·勇`为1费白卡技能，本回合每打出一张攻击牌提升1级蓄力；多段攻击只触发一次，原生重放的每次实际打出均会触发；升级后费用降为0，状态在玩家回合结束时移除。
34. `砥石`为1/0费金卡技能，必须选择并消耗1张其他手牌，然后抽2张牌并提升1级蓄力；卡牌 ID 为`HAMMER_MOD_CARD_WHETSTONE`。
35. `斗志激发`仅对攻击意图敌人提供2/3点能量；`灭气重锤`提供7/10点晕眩；三张蓄力阈值白卡按设计文档中的非翻倍数值结算。
