# 大锤猎手卡牌描述重写提案

> 审阅稿，不直接代表已实现文本。共88个卡牌模型（87种可收集牌、1种战斗中生成的状态牌），按句式分为11类，每张牌仅出现一次。

## 本轮改动评估

### 可直接按文案落地

- 蓄力档位牌的实时行统一去掉“能”，改为“当前造成……”或“当前获得……”。
- 至少2级蓄力牌统一使用“若当前至少拥有2级蓄力，则改为……”句式。
- 龙卷风摧毁停车场、超蓄力、KO术、挑战者、破坏王、再来一锤、蓄力变化·武、预判走位及角色说明按下文统一措辞。
- 全部卡牌描述不使用分号，复合条件改用逗号或拆句。

### 需要同步修改机制

- **释放蓄力关键字**：可以实现。RitsuLib支持注册模组关键字，并将其写入原版卡牌的 `Keywords` 集合、自动插入卡面文字和生成悬停说明。建议将“释放蓄力”注册为正式关键字，自动显示在全部6张释放蓄力牌上，悬停说明为“这张牌完成全部释放后，清空蓄力等级。”底层仍以 `IChargeReleaseCard` 识别机制，关键字负责展示和原版式交互。
- **手摇拖拉机**：释放蓄力牌的重放序列已统一快照首次释放前的蓄力，资源清空与满蓄触发延后到最后一次释放完成后，整组释放只触发一次清空。
- **迎面相杀**：当前条件是“本回合打出过攻击牌”，需要替换为逐个记录攻击过玩家的敌人。由于玩家通常在敌方回合结束后才使用技能牌，下文按“上一敌方回合中攻击过你”定义有效窗口，否则“本回合攻击过你”在正常玩家回合中没有可选目标。完全格挡的攻击也应计为攻击过，多段攻击只记录一次。
- **头重脚轻**：应从伤害命令改为直接降低当前生命，参照官方“灾厄”的生命变更路径。该效果不视为攻击伤害，不经过格挡、力量、易伤或单次伤害上限，但仍不能把生命降到设计允许范围之外。
- **冲击爆裂**：由“每段造成1晕眩，升级降费”改为“每张多段攻击按最终段数统一造成晕眩，升级倍率变为2”。因此升级不再降费，费用保持2费。
- **硬化粉尘**：由全队8/11格挡改为全队永久敏捷，属于明显的强度跃升。审阅稿暂建议1点敏捷，升级2点敏捷，费用、稀有度和多人限定不变，数值需确认后再实现。

### 需要确认的结算口径

- **客制吸血**：按整张攻击令每个敌人失去的总生命值分别计算，回复其除以10后的整数部分。多段攻击会先合并同一目标的生命损失，过量伤害不计。
- **破坏王**：下文的“每次攻击后”按每张攻击牌对每名敌人最多触发一次理解。多段牌只要任意一段造成未格挡生命伤害便触发，AOE对每名敌人分别检查。
- **冲击爆裂**：下文按卡牌最终实际攻击段数计算，包含再来一锤增加的段数，并在整张牌攻击结束后统一施加。暂按不要求造成未格挡伤害处理，AOE对每名目标分别施加。

## 统一规则

- 伤害统一使用“造成X点伤害”。
- 晕眩统一使用“造成X点晕眩”。
- 对敌人施加虚弱或易伤统一使用“给予X层虚弱/易伤”。
- 意图相关牌先写基础效果，再写“如果敌人的意图……”。
- 有使用条件的牌先写“只有当……时才能打出”，再写实际效果。
- 蓄力档位牌始终展示各档数值，战斗中另起一行显示括号内的当前结果。
- 释放蓄力牌在描述前自动显示模组关键字“释放蓄力”，正文不再重复手写“释放蓄力。”。
- `InCombat` 与 `IsTargeting` 是官方条件语法，仅用于控制实时行的显示场景。

## 六、限制打出条件（4张）

- **收锤居合**：只有当蓄力等级至少为1级时才能打出。失去所有蓄力等级，每级蓄力等级转化为 {EnergyPerCharge:energyIcons()}。
- **乘胜追击**：只有当任意敌人处于击晕状态时才能打出。获得 {Energy} 点能量，抽 {Cards} 张牌。
- **迎面相杀**：只有对上一敌方回合中攻击过你的敌人才能打出。目标对你造成的攻击伤害降低100%，持续到敌方回合结束。获得 {StrengthPower:diff()} 点力量。
- **回复药**：只有当没有敌人的意图是攻击时才能打出。获得 {RegenPower:diff()} 点再生。

## 七、能力与持续触发（23张）

- **超蓄力**：本回合内免费打出释放蓄力的牌，且打出时不清空蓄力等级。基础版消耗，升级后移除消耗。
- **集中**：在你的回合开始时，获得1级蓄力。如果蓄力已满，改为抽 {FullCards:diff()} 张牌。

- **打桩高手**：攻击牌对有晕眩值的敌人造成的伤害提高 {StunBonusPercent:diff()}%，如果敌人处于击晕状态，则改为提高 {KnockedOutBonusPercent:diff()}%。
- **震荡共鸣**：每当你给予敌人虚弱或易伤时，每次给予对其造成 {Stun:diff()} 点晕眩。

- **挑战者**：在你的回合开始时，如果任意敌人的意图是攻击，则本回合获得 {StrengthPower:diff()} 点力量。

- **越砸越疼**：每当你以3级以上蓄力等级打出释放蓄力的牌时，获得 {StrengthPower} 点力量。

- **客制吸血**：每次攻击后，敌人失去生命数值除以10的整数部分将转化为你的生命。
- **手摇拖拉机**：本回合内，下一张释放蓄力的牌额外释放一次。全部释放结束后，再清空蓄力等级。
- **蓄力变化·武**：根据当前蓄力等级，增加同等数值的力量。
  `{InCombat:\n（当前获得 {StrengthPower} 点力量）|}`
- **震荡护身**：获得等同于所有敌人当前晕眩值总和的格挡。
  `{InCombat:\n（当前获得 {Block:diff()} 点格挡）|}`
- **翔虫受身**：在下个敌方回合中，第一次受到未被格挡的攻击伤害后，后续所有攻击对你造成的伤害降低至0。基础版消耗，升级后移除消耗。
- **回家玉**：移除你的所有状态并结束回合。下个敌方回合中，你不会受到任何伤害，不会被添加状态，也不会被塞牌。基础版消耗，升级后移除消耗。

- **激运票**：战斗结束时，可以重掷1次卡牌奖励。升级后费用由2降为1。
- **蓄力变化·勇**：本回合内，每打出一张攻击牌，提升 {Charge:diff()} 级蓄力。升级后费用由1降为0。

- **整备**：获得 {Block:diff()} 点格挡，抽 {Cards} 张牌。在你的下回合开始时，再抽 {NextTurnCards} 张牌。
- **快捷调合**：抽 {Cards:diff()} 张牌，然后选择1张手牌放到抽牌堆顶部。
- **重整架势**：获得 {Block:diff()} 点格挡。选择1张弃牌堆中的牌放到抽牌堆顶部。
- **捞飞队友**：选择一名队友。其获得 {Block:diff()} 点格挡与 {StrengthPower} 点力量，并在下回合开始时获得 {Energy} 点能量。将1张“倒地起身”加入其手牌。
- **寻找斜坡**：选择抽牌堆中的 {Cards:diff()} 张牌，将其放到抽牌堆顶部。

## 角色说明

- **大锤猎人**：通过积累蓄力造成更高伤害。受到较大攻击伤害时会减少蓄力层数，未格挡伤害每达到5点就降低1层蓄力等级。可以积累晕眩来击晕敌人。善于根据敌人的意图灵活应对。

## 落地时需要同步的行为与变量

1. **余势不绝、越砸越疼**：触发条件应使用“释放前蓄力等级至少为3”，不能继续使用“等于当前最大蓄力”。否则未来最大蓄力提高到4或更高后，3级以上释放可能无法触发。
2. **越转越稳**：需要新增用于卡面实时展示的 `ResolvedBlock` 与 `ResolvedCharge` 动态变量，并确保抽牌堆、手牌、弃牌堆和消耗牌堆均能刷新。
3. **超蓄力**：基础版带消耗，升级与升级预览时移除消耗。
4. **蓄势待发、蓄力垫步**：当前代码以固定3级判断“已满”。若未来上限可变，应改为读取蓄力资源的实时最大值。
5. **名称同步**：`蓄力纵挥`改为`蓄势纵挥`，`蓄力横挥`改为`蓄势横挥`，正式实现时同时更新中英文标题、文档和测试。
6. **释放蓄力关键字**：注册模组关键字，并将其加入大地一击、浑身蓄力敲打、浑身蓄力回旋、浑身蓄力翻滚、浑身蓄力升龙、天地大冲撞。关键字只负责分类、卡面文字与悬停提示，实际判定仍使用统一接口。
7. **手摇拖拉机**：快照、资源清空和满蓄释放触发必须以整组释放为边界。第二次释放结束前，蓄力变化·武提供的力量不得因蓄力被提前清空而变化。
8. **迎面相杀**：新增敌人攻击记录，并在选取目标、卡牌可用性、金色发光和实际打出校验四处复用同一判定。记录窗口按上一敌方回合定义，攻击被完全格挡仍记入。
9. **头重脚轻**：改用直接生命变更接口，验证其绕过格挡、易伤、力量、无实体和单次伤害上限，同时明确该生命损失是否触发敌人的生命损失监听。
10. **冲击爆裂**：新增最终攻击段数的按牌聚合，不能继续依赖每段 `AfterDamageGiven` 直接加晕眩。段数应包含再来一锤的增量，AOE逐个目标施加，升级由降费改为倍率2倍。
11. **硬化粉尘**：将 `BlockVar`、`GainsBlock` 和全队格挡命令替换为 `PowerVar<DexterityPower>` 与全队能力施加，暂按1/2敏捷设计。
